# EVM: Solidity con Foundry (Ethereum, Arbitrum, Base, Optimism, Polygon, BSC, Avalanche)
- Proyecto: `forge init NOMBRE` (crea src/, test/, script/ y descarga forge-std con git). Si la carpeta ya existe: `forge init --force .`. Librerías: `forge install OpenZeppelin/openzeppelin-contracts` y en foundry.toml `remappings = ["@openzeppelin/=lib/openzeppelin-contracts/"]`.
- foundry.toml: `solc_version = "0.8.28"` fija, `optimizer = true`, y por red `[rpc_endpoints]` con variables: `sepolia = "${RPC_SEPOLIA}"`, `arbitrum = "${RPC_ARBITRUM}"`.
- Solidity 0.8.x: `pragma solidity ^0.8.24;`, errores personalizados (`error SinSaldo();` + `revert SinSaldo();`), eventos en cada cambio de estado, `immutable`/`constant`, sin `tx.origin`. Patrón checks-effects-interactions; `ReentrancyGuard`, `Ownable`/`AccessControl` y `SafeERC20` de OpenZeppelin para tokens externos.
- Tests (`test/X.t.sol`, `import {Test} from "forge-std/Test.sol";`): `setUp()`, `assertEq`, `vm.prank(usuario)`, `vm.expectRevert(Contrato.Error.selector)`, `vm.deal`, `vm.warp`; fuzz con parámetros (`function testFuzz_deposito(uint96 monto) public`), invariantes (`invariant_...`). Contra el estado real: `vm.createSelectFork(vm.envString("RPC_MAINNET"))` (solo lectura).
- `forge build`, `forge test -vvv` (muestra la traza del fallo), `forge fmt`, `forge coverage`. Gas: `forge test --gas-report`.
- Desplegar en local: `ejecutar("anvil", fondo=true)` y `forge script script/Deploy.s.sol --rpc-url http://127.0.0.1:8545 --broadcast --unlocked --sender 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266` (primera cuenta de prueba de anvil). Comprueba con `cast call DIRECCION "total()(uint256)" --rpc-url http://127.0.0.1:8545`. En un deploy.bat: si `cast block-number --rpc-url http://127.0.0.1:8545` falla, arranca el nodo con `start "anvil" /min anvil` y espera a que responda; nunca lo cierres con `taskkill /IM` (cierra los de todo el equipo).
- Otra red (pide permiso): `forge script ... --rpc-url sepolia --broadcast --account NOMBRE_KEYSTORE`; verificar el código en el explorador: `forge verify-contract` (también pide permiso).
- Hardhat (si el usuario lo prefiere o el proyecto ya lo usa): `version("hardhat", "npm")`, tests en TypeScript con `npx hardhat test`, despliegue con Ignition (`npx hardhat ignition deploy ignition/modules/X.ts --network localhost`). Redes en hardhat.config con `url: process.env.RPC_X`.
- Clientes y bots: TypeScript con `viem` (`createPublicClient`, `createWalletClient`, `watchBlocks`, `simulateContract` antes de `writeContract`); Rust con `alloy`; Python con `web3`. ABI desde `out/X.sol/X.json` de Foundry.
- Analizador estático opcional: `slither .` si está instalado (`pip install slither-analyzer`).
